# Commencer

Suivez ce parcours pour passer d'une vue d'ensemble à un premier environnement. Les commandes ont été relevées dans les sources ; la validation avec un nouveau membre reste à réaliser.

## Parcours de prise en main

1. Lire la [vue d'ensemble](vue-ensemble.md) et le [glossaire](glossaire.md).
2. Consulter la [carte des services](../architecture/services.md) pour choisir les composants utiles.
3. Préparer les accès et les dépendances avec la [configuration](../developpement/configuration.md).
4. Suivre le [démarrage](../developpement/demarrage.md), puis comprendre l'[authentification](../developpement/authentification.md).
5. Réaliser la [validation locale](../developpement/validation-locale.md) avec des données fictives et noter le résultat.

Pour une intervention sur le site public, suivre la [fiche site-vitrine](../services/site-vitrine.md) : son environnement diffère de celui de l'intranet.

## À compléter avant de certifier l'onboarding

- Confirmer les responsables d'accès aux dépôts, à l'identité et aux intégrations.
- Valider les versions de runtime et les modèles de configuration.
- Préparer des données et identités de test réellement synthétiques.
- Faire suivre ce parcours par une personne qui ne connaît pas le projet.
