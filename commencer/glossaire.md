# Glossaire

Ces définitions servent à lire la documentation. Les termes métier doivent être confirmés avec leurs responsables.

| Terme | Sens dans cette documentation |
| --- | --- |
| SiWeb | Équipe qui développe les applications. |
| SiOps | Équipe qui exploite l'infrastructure. |
| Intra | Frontend de l'intranet, dépôt `intra`. |
| Promotion | Groupe/cohorte utilisé pour organiser les données et parcours académiques ; les règles de changement d'année restent à confirmer. |
| PAE | Domaine fonctionnel géré notamment par Notes : affectations, évaluations, échéances et duplication. L'intitulé institutionnel et les règles détaillées restent à valider. |
| Scolarité | Service de données communes concernant notamment les personnes, promotions et cours. |
| Yearbook | Application liée aux profils, événements et contenus d'une promotion. |
| Cassiopée | Passerelle applicative SiWeb vers une API de ressources SiOps. |
| Sous-module | Dépôt Git indépendant référencé à un commit précis par `local-environment`. |
| Référence examinée | Révision du code utilisée pour écrire un chapitre ; elle peut différer du code déployé. |
| Brouillon | Contenu initial dont les limites de vérification sont indiquées. |
| Vérifié | Contenu ayant fait l'objet de la vérification indiquée, pour une référence et un contexte précis. |

Compléter ce glossaire au fil des [parcours métier](../metier/index.md), plutôt que d'inventer une définition à partir d'un nom de fichier.
