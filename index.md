# Documentation du projet SIGL

Ces pages décrivent l'état actuel de l'environnement de développement commun. Leur source de vérité est le dépôt privé `SIGL-SIWEB/local-environment`. Le [site GitHub Pages](https://sigl-siweb.github.io/siweb-docs/) en est une copie de lecture ; les modifications se font dans le dépôt source.

- [Services et dépendances](architecture/services.md) : rôle des dépôts et communications locales.
- [Démarrer le projet](developpement/demarrage.md) : prérequis, installation et commandes disponibles.
- [Contribuer](developpement/contribution.md) : modifier un service, intégrer son sous-module et tenir la documentation à jour.
- [Dépannage](exploitation/depannage.md) : premiers contrôles de l'environnement local.

Les détails propres à un service restent dans son dépôt. Les documents de `docs/superpowers/` sont des plans et décisions historiques ; ils ne remplacent pas cette référence ni le code courant.
